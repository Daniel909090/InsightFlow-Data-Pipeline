# DataBridge AI API

DataBridge AI API is a Python-based project in development that connects internal data with an AI model through an API.

## Planned Features
- Load and process internal documents
- Split text into chunks
- Retrieve relevant data
- Send data to AI API
- Return structured response
- Docker support

## Technologies
- Python
- FastAPI
- OpenAI API
- Docker
